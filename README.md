# Xray Config Tester Bot

ربات تلگرام برای جمع‌آوری، تست و فیلتر کانفیگ‌های Xray روی Railway.

## قابلیت‌ها

- راه‌اندازی اولیه از صفحه وب (توکن ربات + آیدی مدیر)
- استخراج کانفیگ از پیام، فوروارد و فایل متنی
- پشتیبانی از vless / vmess / trojan / ss
- جمع‌آوری از لینک سابسکریپشن (base64 و متنی)
- مانیتور کانال (اگر ربات ادمین باشد)
- تست واقعی با هسته Xray + اندازه‌گیری latency
- تشخیص کشور و پرچم از IP خروجی
- انتخاب top 20 و تغییر ریمارک
- ضدتکرار ۲۴ ساعته
- زمان‌بندی خودکار (چند نوبت در روز)
- دیپلوی به گیت‌هاب از داخل ربات (فقط مدیر اصلی)
- ذخیره پایدار روی Volume

## دیپلوی روی Railway

1. کل محتویات این پوشه را در یک ریپوی گیت‌هاب بگذار
2. در Railway یک سرویس جدید از همان ریپو بساز
3. یک **Volume** بساز و به مسیر `/app/data` مانت کن
4. دیپلوی کن
5. دامین سرویس را باز کن و توکن ربات + آیدی عددی خودت را وارد کن
6. در تلگرام `/start` بزن

## Volume (مهم)

```
Mount Path: /app/data
```

بدون Volume بعد از ری‌استارت تنظیمات پاک می‌شود.

## دستورات

| دستور | توضیح |
|--------|--------|
| `/start` | منوی اصلی |
| `/pending` | تعداد کانفیگ در صف |
| `/clear_pending` | پاک کردن صف (فقط owner) |
| `/cancel` | لغو عملیات جاری |
